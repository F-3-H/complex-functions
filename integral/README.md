# 复变函数积分计算器

一个交互式的复变函数积分可视化工具。

## 功能

- **z 平面绘制**：画笔、直线、折线、三点圆弧、圆、矩形等多种绘图工具
- **w 平面积分可视化**：实时展示 f(z)·dz 矢量首尾相加的积分过程
- **自定义函数**：支持完整复变函数语法（sin, cos, exp, log, sqrt, conj 等）
- **多线段对比**：支持绘制多条独立线段，分别积分对比
- **动画播放**：逐步展示积分累加过程
- **网格吸附**：绘图时自动吸附到网格交点

## 使用方式

直接在浏览器中打开 `index.html` 即可使用。
