# 复变函数计算器 · e^(iθ) 相位矢量动画（含衰变系数）

单文件 HTML 应用，无需安装、无依赖，浏览器直接打开 `index.html` 即可（或通过本地静态服务器访问）。

## 功能（与需求的对应）

| 需求 | 实现 |
| --- | --- |
| 1. 两个面板 | 左侧「自变量面板」一维 θ 轴；右侧「因变量面板」复平面（Re/Im） |
| 2. 两点成线、自动慢移 | θ 轴上点两个点形成线段（起点/终点），θ 自动缓慢移动，右侧端点同步运动 |
| 3. 矢量首尾相接 | 每个 e^(...) 项对应一个矢量，按书写顺序首尾相接、共用运动；端点轨迹即函数图 |
| 4. 系数常数 | 单位系数改模长、θ 系数改转速、相位常数 b 改初始角 |
| 4′. 衰变系数 | 指数可含实数部分：`e^(-θ)`、`e^(-0.3θ)e^(iθ)`、`e^((-1+i)θ)` —— 模长随 θ 衰减/增长，曲线变为（对数）螺旋 |
| 5. 自定义函数 | 任意 Σ c·e^(pθ)·e^(i(aθ+b)) 线性组合 |
| 6. 虚线圈 | 每个矢量一个以矢尾为圆心、模长为半径的虚线圆，半径随衰变实时变化 |

## 使用

1. 输入函数（或点预设）→ 应用/回车。
2. 在左侧 θ 轴点两点设置线段（第二次点击后自动播放）。
3. 播放控制：播放/暂停、回到起点、时长（1–30s）、循环模式（往返/单程/循环）。
4. 手动拖动 θ 滑条微调。
5. 因变量面板：滚轮缩放、拖动平移（触屏单指平移/双指缩放）、显示开关、适应视图。

### θ 轴操作（自变量面板）
- **滚轮**：以光标为锚点缩放 θ 轴范围
- **按住空白处拖动**：平移 θ 轴范围
- **拖拽「起点/终点」标记**：微调线段端点（曲线实时更新）
- **拖拽蓝色 θ 圆点**：手动改变 θ
- **点击空白处**：设置新的起点/终点（第二次点击后自动播放）
- **「吸附刻度」**：点击设置点时吸附到当前刻度（刻度随缩放自适应）
- **「＋放大/－缩小/重置范围」**按钮：快捷缩放与恢复 0~2π

## 语法

```
f(θ) = Σ cₖ·e^(pₖθ)·e^(i(aₖθ + bₖ))
```

- 数字、`π`(pi)、`i`、`θ`(theta，仅限 e^ 指数内)
- `e^(...)` 或 `exp(...)`；指数为复数线性式 (p+iq)θ + (u+iv)：
  - 纯旋转：`iθ`、`2iθ`、`i(2θ+π/2)`、`iθ+i2θ`（= e^(i3θ)）
  - 衰变/增长：`-θ`、`e^(-θ)`、`e^(-0.3θ)e^(iθ)`、`e^((-1+i)θ)`、`e^(0.1θ)e^(iθ)`
- 运算符 `+ - * /` 与隐式乘法：`2e^(iθ)`、`πe^(iθ)`、`e^(iθ)e^(i2θ)`、`(2+i)e^(iθ)`
- 示例：`e^(iθ)+e^(i2θ)`、`3e^(iθ)+2e^(-i2θ)+e^(i3θ)`、`2e^(-0.2θ)e^(iθ)+e^(-0.4θ)e^(i2θ)`

## 说明与限制

- θ 只能出现在 e^ 的指数中，且指数中 θ 必须为线性（不支持 θ²）。
- 指数中不允许 θ 的乘积或除以含 θ 的项。
- 模长超过显示半径 10⁴ 的部分会被截断（避免数值溢出），发散函数请缩小 θ 范围查看。
- 矢量按书写顺序首尾相接；加法可交换，顺序不影响最终端点。
- 函数曲线按当前线段范围绘制；未设置线段时按 θ 轴范围绘制。
